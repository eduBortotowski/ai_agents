# Outras linguagens e SQL

Aplique o guia oficial ou consagrado da linguagem detectada e **informe qual guia usou como referência**. Exemplos:
- Go: Effective Go
- Java: convenções do Spring / Google Java Style
- PHP: PSR-12
- C#: guidelines da Microsoft
- Rust: Rust API Guidelines

## SQL (inclusive Oracle)
- Parâmetros em vez de concatenação de strings.
- Evitar `SELECT *`.
- Índices e planos de execução em consultas pesadas.
- Transações explícitas onde houver múltiplas escritas.
